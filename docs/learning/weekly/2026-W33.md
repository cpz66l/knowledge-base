## 项目表达产出要求

### 1 分钟介绍

要求：控制在 250-350 字，回答“项目是什么、你做了什么、最核心技术点是什么、怎么验证”。

### 3 分钟介绍

要求：按以下顺序讲：

1. 项目目标：15 分钟单局闭环和背包构筑核心循环。
2. 系统拆分：战斗、掉落、背包、邻接构筑、波次、结算。
3. 技术亮点：纯 C# 背包、RuleBook / Resolver、对象池、WaveDirector、Profiler / Build。
4. 真实 Bug：选 2 个讲排查过程。
5. 不足和后续：新手引导、构筑内容、经济闭环、配置化和表现包装。
