## C++ 小程序建议

优先从下面二选一：

| 练习 | 最小验收 |

## 计网 / OS 最小问答卡

本周只要完成 2 条：

| 主题 | 要回答的问题 | 验收方式 |
|---|---|---|
| TCP | 为什么 TCP 建连接是三次握手，不是两次？ | 用自己的话写 5-8 行；能提到历史连接、双方收发能力确认 |
| HTTP | 一次 HTTP 请求从输入 URL 到返回页面大概发生什么？ | 画文本流程：DNS -> TCP -> HTTP -> 响应 -> 渲染 |
| OS | 进程和线程有什么区别？游戏客户端里什么时候要小心线程？ | 能提到资源拥有、调度单位、共享内存、Unity 主线程边界 |
