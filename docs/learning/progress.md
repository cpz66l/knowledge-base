## 进度文档怎么维护

这份文档是“当前能力快照”，不是单次计划本身。

- 每次生成计划前，先根据本页确认当前短板和优先级。
- 平时把题解、代码、笔记、项目讲稿、投递记录等原始证据放进 `inbox/`。
- 用户要求整理时，将本次材料追加到对应周学习记录，再按证据更新本页状态和下一步重点。
- 没有证据的新内容保持“待验证”或“待补证据”，不为了进度好看提前标记掌握。

## 下一周学习安排来源

根据当前基线，下一周不急着开新项目，重点是建立学习节奏和证据格式：

1. 算法恢复：每天 1 题，优先用 C++ 留下题解、复杂度、错点和提交证据。
2. C++ 基础：用链表 / 二叉树题继续补指针、引用、递归边界、`vector`、`string`、`unordered_map` 和 `stack`。
3. 项目表达：C# 主要通过 Backpack Survivor 工程训练，整理 1 分钟和 3 分钟讲稿。
4. 计网 / OS：每天小步学习高频面试内容；计网下一步先补 TCP/UDP，OS 先补进程 / 线程。
5. 进度系统：用第一篇周学习记录验证“计划 -> 执行 -> 证据 -> 复盘 -> 更新进度”的闭环。
