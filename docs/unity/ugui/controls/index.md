# 核心控件

> UGUI 常用交互控件一览 - 搭建功能界面的积木。

## 控件一览

| 控件 | 核心用途 | 关键属性 |
|------|----------|----------|
| [Text (TextMeshPro)](text-tmp.md) | 文字显示 | 字体、字号、富文本、SDF 渲染 |
| [Image](image.md) | 图片显示、填充条 | ImageType、Raycast Target |
| [Button](button.md) | 点击交互 | onClick、Transition |
| [Toggle](toggle.md) | 开关/复选 | isOn、Toggle Group |
| [Slider](slider.md) | 数值选择、进度条 | Value、Min/MaxValue、OnValueChanged |
| [Scrollbar](scrollbar.md) | 滚动定位 | Value、Size、NumberOfSteps |
| [Dropdown](dropdown.md) | 下拉选择 | Options、Value、OnValueChanged |
