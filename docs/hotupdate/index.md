## 为什么需要热更新

App Store / 应用商店审核周期长，游戏更新频繁。热更新让你：

- **不经过商店审核**就能修复线上 Bug
- **快速迭代**活动和玩法，不用发新版本
- **减少包体大小**：Lua 脚本随资源包下载

## 主流方案对比

| | xLua | ToLua | SLua |
|------|------|------|------|
| **维护方** | 腾讯 | 社区 | 社区 |
| **C# 调用 Lua** | ✅ 完善 | ✅ | ✅ |
| **Lua 调用 C#** | ✅ 优秀（代码生成） | ✅ | ✅ |
| **热补丁** | ✅ 支持 | ❌ | ❌ |
| **上手难度** | 中等 | 中等 | 较高 |

> 💡 推荐 **xLua**：腾讯出品，生态最好，热补丁功能独一无二
