## 简介

《背包幸存者》V0.3.0 是一个 Unity 3D 俯视角生存射击 Demo。玩家需要在 15 分钟单局中移动、射击、搜刮、整理背包，并通过武器激活、合并升级、邻接芯片、背包被动物品和升级三选一形成构筑成长。

## V0.3 主要更新

- 扩展升级三选一候选池，新增攻击、生存、机动、搜刮和构筑方向。
- 扩展背包构筑效果，加入瞄准镜暴击、机械臂激活上限、护甲减伤和磁吸核心拾取范围。
- 扩展内容池与物品价值体系，补充更多高价值收集品、传说物品和专属图标。
- 接入基础音频系统、分武器射击音效、UI 音效、胜负音效和 BGM。
- 新增设置菜单，支持 Master / SFX / Music 音量、分辨率和窗口模式。
- 优化敌人群体移动，加入分离力、障碍避让、方向平滑和错峰采样。
- 新增远程敌人和波次混编，中后期出现更明显的走位压力。
- 新增本地 JSON 存档，记录总局数、胜场、最高背包价值、局外金币和传说带出数据。
- 完成 V0.3 Profiler 快扫和 Windows Build 验收记录。

## 运行方式

1. 下载 `BackpackSurvivor_v0.3_Windows.zip`。
2. 解压整个压缩包。
3. 双击 `BackpackSurvivor.exe` 启动。

不要只单独运行 exe；游戏还需要同目录下的 `BackpackSurvivor_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等文件。

## 操作说明

| 操作 | 输入 |
|---|---|
| 移动 | `WASD` |
| 瞄准 | 鼠标指向地面 |
| 主动射击 | 鼠标左键 |
| 交互 / 拾取装备 / 开宝箱 | `E` |
| 打开或关闭背包 | `Tab` |
| 拖拽物品 | 鼠标左键拖拽 |
| 旋转背包物品 | 拖拽中按 `R` |
| 暂停 | `Esc` |
