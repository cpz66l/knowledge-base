## 新增重点

### BUG-024 · 主动射击鼠标指向与子弹视觉方向不一致

问题发生在等距相机和不同高度平面之间：鼠标射线打到地面点后，再拿这个点驱动枪口高度的水平弹道，会让玩家看到的鼠标方向和子弹视觉方向错层。

修复思路是让输入层提供按高度取点的方法：主动武器使用枪口高度，角色朝向使用身体高度，地面语义仍可使用地面点。

### BUG-025 · Build 中子弹与装备掉落物颜色异常

问题只在 Build 中明显暴露，根因指向运行时 `CreatePrimitive` 依赖默认材质的脆弱性。修复思路是给子弹和装备掉落物都提供显式运行时视觉材质，并通过 `MaterialPropertyBlock` 写实例颜色。

这条 Bug 的价值在于提醒：Editor 里默认材质“看起来正常”不能代替 Build 资源链路验收。
