# 面试与表达检查清单

> 面试准备应建立在已经学习和实践的内容上，不提前背诵没有验证过的结论。

---

## 算法

- [ ] 能先说明思路和复杂度，再开始写代码
- [ ] 能处理边界条件和失败用例
- [ ] C# 与 C++ 至少有一种语言能够熟练完成
- [ ] 复盘过错误原因，而不只保存最终答案

算法入口：[C# LeetCode](../csharp/leetcode/index.md)与[C++ LeetCode](../cpp/leetcode/index.md)。

## 原理

- [ ] 能结合项目解释 C# 内存、GC、事件和异步
- [ ] 能结合实验解释 C++ 生命周期、RAII、STL 和并发
- [ ] 能说明 Unity 生命周期、资源管理和性能定位过程
- [ ] 不确定的内容能够明确说明边界，而不是强行回答

## 项目表达

- [ ] 能在 1 分钟内说明项目目标和个人职责
- [ ] 能画出核心模块和数据流
- [ ] 能说明一个技术取舍及其替代方案
- [ ] 能讲清一个难题的定位和验证过程
- [ ] 能提供性能、测试或运行结果作为证据
- [ ] 能说明项目还存在哪些不足
