# 专项能力检查清单

> 每次只选择当前项目需要的专项。没有项目需求时，不必提前完成全部内容。

---

## 性能优化

- [ ] 先测量再优化，并保留优化前数据
- [ ] 能判断瓶颈主要在 CPU、GPU、内存还是 IO
- [ ] 优化后使用相同场景重新测量
- [ ] 记录收益、代价和适用平台

## 图形学

- [ ] 能说明当前实验处于渲染管线的哪个阶段
- [ ] 能通过画面或 RenderDoc/Frame Debugger 验证结论
- [ ] 能解释 Shader 输入、输出和关键参数
- [ ] 记录效果、成本和限制

## 网络编程

- [ ] 能画出客户端、服务端与消息流
- [ ] 能说明当前使用 TCP、UDP 或框架方案的理由
- [ ] 测试过延迟、断线或异常消息流程
- [ ] 能说明状态同步或帧同步的基本取舍

## 热更新

- [ ] 能说明代码更新和资源更新的边界
- [ ] 有版本号、校验、失败处理和回滚意识
- [ ] 更新流程经过一次完整验证
- [ ] 记录平台限制和安全风险
