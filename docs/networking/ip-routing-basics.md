## 网络层服务：虚电路 vs 数据报

| 对比维度 | 虚电路服务 | 数据报服务（IP） |
|---|---|---|
| 建立连接 | 传输前先建立虚电路 | 不建立网络层连接，直接发送数据报 |
| 路径 | 同一通信的分组走固定路径 | 每个分组独立按路由表转发 |
| 到达顺序 | 更容易按序到达 | 可能乱序，端系统需要处理 |
| 路由器状态 | 路由器维护虚电路状态 | 路由器尽量无状态，只查表转发 |
| 故障处理 | 固定路径断开会影响整条虚电路 | 分组可根据路由变化绕行 |
| 典型代表 | ATM、帧中继等 | 互联网 IP |

互联网选择数据报服务，是为了让网络核心保持简单、可扩展和抗故障。复杂的可靠传输、有序交付、流量控制等能力更多交给端系统中的 TCP 或应用层处理，这也是端到端原则的典型体现。

一个易混点：**虚电路不等于 TCP 连接**。虚电路是网络层为分组转发路径维护状态；TCP 连接是运输层的端到端逻辑连接，并不指定每个 IP 分组必须走同一条物理路径。

## IP 地址与子网

IPv4 地址是 32 位二进制标识，通常写成点分十进制，例如 `128.11.3.31`。传统分类地址把 IP 分成网络号和主机号：

| 类别 | 开头位 | 网络号 | 主机号 | 首字节范围 | 用途 |
|---|---|---:|---:|---|---|
| A | `0` | 8 位 | 24 位 | 1-126 | 超大型网络 |
| B | `10` | 16 位 | 16 位 | 128-191 | 中型网络 |
| C | `110` | 24 位 | 8 位 | 192-223 | 小型网络 |
| D | `1110` | - | - | 224-239 | 组播 |
| E | `1111` | - | - | 240-255 | 保留 |

`127.0.0.1` 属于回环地址，所以 A 类常见可用首字节从 1 到 126。

现代网络不再主要依赖 A/B/C 分类，而是使用子网掩码和 CIDR。CIDR 用 `IP/前缀长度` 表示网络号位数，例如 `192.168.1.0/24`。

```text
网络地址 = IP 地址 & 子网掩码
```

面试计算时常用两个公式：

- 可用主机数：`2^主机位数 - 2`。
- 从 `/24` 切到 `/26`，新增 2 位子网位，所以可切成 `2^(26 - 24) = 4` 个子网；每个 `/26` 子网可用 `2^6 - 2 = 62` 台主机。

## ARP、NAT、VPN 与 IPv6

| 概念 | 作用 | 面试表达 |
|---|---|---|
| ARP | 已知 IP，查询同一局域网内对应 MAC 地址 | IP 决定最终目标，MAC 决定下一跳交付对象 |
| RARP | 已知 MAC，反查 IP | 历史协议，现代场景较少直接使用 |
| NAT | 把内网私有地址转换为公网地址 | 缓解 IPv4 地址不足，也是家庭路由器常见能力 |
| VPN | 利用公网建立虚拟专用网络 | 常通过隧道技术承载私有网络通信 |
| IPv6 | 使用 128 位地址 | 冒号十六进制表示，可用 `::` 压缩连续 0，但同一地址中只能出现一次 |

IPv4 到 IPv6 过渡常见思路包括双协议栈和隧道技术。

## 路由选择协议

路由协议先分清范围：AS 内部用 IGP，AS 之间用 EGP。

| 对比项 | IGP | EGP |
|---|---|---|
| 范围 | 自治系统 AS 内部 | 自治系统之间 |
| 代表 | RIP、OSPF | BGP |
| 目标 | 找较优路径 | 找可达路径，并考虑策略 |
| 关注点 | 距离、带宽、收敛速度 | 商业、政治、安全和运营策略 |

### RIP：距离向量

- 度量：跳数，最多 15 跳，16 跳视为不可达。
- 交换对象：相邻路由器。
- 交换内容：自己的完整路由表。
- 交换时机：周期性广播。
- 特点：实现简单，但收敛慢，适合小型网络。

### OSPF：链路状态

- 度量：链路代价，通常和带宽有关。
- 交换对象：向区域内路由器泛洪链路状态。
- 算法：每台路由器基于全网拓扑用 Dijkstra 计算最短路径。
- 特点：收敛快、适合大型网络，但实现和资源成本更高。

### BGP：自治系统之间的可达性

- 作用：在 AS 之间交换可达网络和路径属性。
- 传输：基于 TCP，端口 179。
- 重点：BGP 不单纯追求最短路径，而是根据 AS 路径、优先级和策略选择可达路径。

一句话区分：RIP 简单但只看跳数，OSPF 知道区域内拓扑并计算最短路径，BGP 更像 AS 之间的策略协商。

## 面试追问

- 为什么互联网核心选择数据报服务，而不是虚电路服务？

- 子网掩码和 CIDR 解决了传统分类地址的什么浪费问题？
- ARP 查询的是最终目的主机，还是下一跳的 MAC？
- RIP 和 OSPF 为什么一个收敛慢、一个收敛快？
- BGP 为什么更强调策略，而不是最短路径？
