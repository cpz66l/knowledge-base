# 搜索二维矩阵 II ⭐ 重点

> [LeetCode 240. Search a 2D Matrix II](https://leetcode.cn/problems/search-a-2d-matrix-ii/) - Medium

!!! warning "高频重点"
    矩阵**搜索空间缩减**的经典题。不是简单的二分，而是利用"每行左到右递增、每列上到下递增"的双向排序特性，从**左下角**或**右上角**出发，每次比较排除一整行或一整列。时间复杂度 **O(m+n)**，比逐行二分 O(m log n) 更优，且是面试标准解法。

编写一个高效的算法来搜索 `m × n` 矩阵 `matrix` 中的一个目标值 `target`。该矩阵具有以下特性：

- 每行的元素从左到右升序排列
- 每列的元素从上到下升序排列

---

## 核心思路

观察矩阵的两个"特殊角落"——**左下角**和**右上角**。这两个位置是所在行和列的"极值交界点"：

```
以左下角 matrix[m-1][0] 为例：
  - 往右 → 值变大（同行递增）
  - 往上 → 值变小（同列递减）

所以：
  matrix[i][j] > target → 当前值太大，往上走（i--）
  matrix[i][j] < target → 当前值太小，往右走（j++）
  matrix[i][j] == target → 找到了 ✓
```

**本质**：每一步排除一整行（向上）或一整列（向右），相当于在 Z 字形缩减搜索空间。最多走 `m + n` 步。

---

```
matrix = [[1,  4,  7,  11, 15],
          [2,  5,  8,  12, 19],
          [3,  6,  9,  16, 22],
          [10, 13, 14, 17, 24],
          [18, 21, 23, 26, 30]]
target = 5

从 左下角 (i=4, j=0) = 18 出发：

[18] > 5  →  太大，往上走  (i--, i=3)    排除第 4 行（整行 > 18 > 5）
[10] > 5  →  太大，往上走  (i--, i=2)    排除第 3 行
[3]  < 5  →  太小，往右走  (j++, j=1)    排除第 0 列（整列 < 3 < 5）
[6]  > 5  →  太大，往上走  (i--, i=1)    排除第 2 行
[5]  == 5 →  找到 ✓                      共走 5 步

搜索路径：(4,0)→(3,0)→(2,0)→(2,1)→(1,1)
```

---

```csharp
public class Solution
{
    public bool SearchMatrix(int[][] matrix, int target)
    {
        int m = matrix.Length;       // 行数
        int n = matrix[0].Length;    // 列数

        // 从左下角出发：当前行最大、当前列最小
        int i = m - 1;   // 行指针，从最后一行开始
        int j = 0;       // 列指针，从第一列开始

        // 边界：行不能越上界，列不能越右界
        while (j < n && i >= 0)
        {
            if (matrix[i][j] > target)       // 当前值比目标大
            {
                i--;                          // 当前行右边更大，整行排除，往上走
            }
            else if (matrix[i][j] < target)  // 当前值比目标小
            {
                j++;                          // 当前列上边更小，整列排除，往右走
            }
            else                              // 相等，找到了
            {
                return true;
            }
        }

        return false;   // 越界还没找到，矩阵中不存在 target
    }
}
```

| 复杂度 | |
|--------|------|
| 时间 | O(m + n)，每步排除一行或一列，最多走 m + n 步 |
| 空间 | O(1)，只用了两个指针变量 |

---

## 方法对比

| 方法 | 时间 | 空间 | 思路 |
|------|------|------|------|
| **左下/右上角搜索（本解法）** | O(m + n) | O(1) | 利用双向排序，每次排除一行或一列 |
| 逐行二分 | O(m log n) | O(1) | 每行做二分查找，没用到列递增 |
| 暴力遍历 | O(mn) | O(1) | 每个元素都看一遍 |

---

## 核心技巧

- **可从右上角出发**也等价：`matrix[i][j] > target → j--`（往左），`< target → i++`（往下）
- **为什么不能从左上/右下出发？** 左上角往右和往下都是变大，没法判断该走哪边；右下角同理都是变小
- 这题和 [搜索二维矩阵 I（LeetCode 74）](../binary-search/search-a-2d-matrix.md) 不同——那题是"整行串联有序"，可以用全局二分 O(log mn)；这题只有行/列各自有序，必须用 Z 字查找

!!! tip "与 LeetCode 74 的区别"
    | | LC 74 | LC 240（本题）|
    |------|-------|------|
    | 矩阵特性 | 每行有序，且下一行首元素 > 上一行尾元素 | 每行有序，每列有序（无全局序） |
    | 最优解 | 全局二分 O(log mn) | Z 字搜索 O(m + n) |
    | 出发点 | 不适用 | 左下角 / 右上角 |
