# 旋转图像 ⭐ 重点

> [LeetCode 48. Rotate Image](https://leetcode.cn/problems/rotate-image/) - Medium

!!! warning "高频重点"
    矩阵**原地旋转**的经典题，考察对矩阵索引关系的数学理解。"转置 + 翻转"的两步法简单高效，是面试中最优解。同类题目还有"旋转矩阵 II（生成螺旋矩阵）"、"螺旋矩阵（遍历）"——掌握了这题的索引变换，整个矩阵旋转类题型都能融会贯通。

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像**顺时针旋转 90 度**。

你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。**不要**使用另一个矩阵来旋转图像。

---

## 核心思路

顺时针旋转 90° 可以拆解为两个简单的矩阵操作：

```
顺时针 90° = 先沿主对角线转置 + 再每行左右翻转
```

**为什么这样是对的？** 矩阵元素 `matrix[i][j]` 顺时针旋转 90° 后的目标位置是 `matrix[j][n-1-i]`。先转置让 `(i,j) → (j,i)`（行列互换），再左右翻转让 `(j,i) → (j, n-1-i)`——两步合起来刚好就是目标坐标，不需要额外空间。

---

```
以 3×3 矩阵为例：

原始矩阵：
     [1, 2, 3]
     [4, 5, 6]
     [7, 8, 9]

Step 1: 沿主对角线转置（swap matrix[i][j] ↔ matrix[j][i]，只遍历右上三角）
     [1, 4, 7]     // (0,1)↔(1,0): 2↔4, (0,2)↔(2,0): 3↔7, (1,2)↔(2,1): 6↔8
     [2, 5, 8]
     [3, 6, 9]

Step 2: 每行左右翻转（reverse each row）
     [7, 4, 1]
     [8, 5, 2]
     [9, 6, 3]

结果：顺时针旋转 90° ✓
```

```
其他旋转方向的等价操作：

逆时针 90°  = 先每行左右翻转 + 再主对角线转置（和顺时针顺序相反）
旋转 180°   = 先主对角线转置 + 再副对角线转置（或：左右翻转 + 上下翻转）
旋转 270°   = 逆时针 90° 再顺时针翻转回去，等价于顺时针 90° 重复 3 次
```

---

```csharp
public class Solution
{
    public void Rotate(int[][] matrix)
    {
        int n = matrix.Length;

        // Step 1：沿主对角线转置 —— 只遍历右上三角 (i, j) 其中 j > i
        // 把 matrix[i][j] 和 matrix[j][i] 交换
        for (int i = 0; i < n; i++)
        {
            for (int j = i + 1; j < n; j++)   // j 从 i+1 开始，只处理右上三角
            {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // Step 2：每行左右翻转 —— 双指针交换每一行的首尾元素
        for (int i = 0; i < n; i++)
        {
            int l = 0;
            int r = n - 1;
            while (l < r)          // 左右指针相遇时停止
            {
                int temp = matrix[i][l];
                matrix[i][l] = matrix[i][r];
                matrix[i][r] = temp;
                l++;
                r--;
            }
        }
    }
}
```

| 复杂度 | |
|--------|------|
| 时间 | O(n²)，每个元素在转置和翻转中各被访问一次 |
| 空间 | O(1)，原地操作，只用了几个临时变量 |

---

## 方法对比

| 方法 | 时间 | 空间 | 思路 |
|------|------|------|------|
| **转置 + 翻转（本解法）** | O(n²) | O(1) | 两步矩阵操作，直观简洁 |
| 四元组旋转 | O(n²) | O(1) | 一圈一圈旋转，每次交换四个角元素 |
| 复制矩阵 | O(n²) | O(n²) | 借助辅助矩阵，不符合原地要求 |

!!! tip "转置遍历范围"
    转置时第二层循环 `j = i + 1` 而不是 `j = 0`，这确保了只遍历**右上三角**（对角线以上的元素）。如果 `j` 从 0 开始会把已经交换过的元素再换回去，等于白做。

!!! tip "旋转方向的记忆法"
    只需要记住**顺时针 = 转置 + 左右翻**，逆时针就是把顺序反过来（左右翻 + 转置）。考试时如果忘了，拿一个 2×2 小矩阵手推一遍就能确认。
