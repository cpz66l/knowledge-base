## 核心技巧

- 标准闭区间二分：`left <= right`，每轮排除一半区间。
- 中点优先写成 `mid = left + (right - left) / 2`，避免 `left + right` 溢出。
- 搜索插入位置本质是找第一个 `>= target` 的下标；可以维护 `ans = n`。
- 二维矩阵若满足“下一行首元素大于上一行尾元素”，可把它当成长度 `m * n` 的一维数组：`row = mid / n`，`col = mid % n`。
