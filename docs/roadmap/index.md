# 学习路线总览

> 本页负责回答三个问题：现在学什么、学完做什么、下一步去哪里。路线中的“待学习”只代表规划，不代表知识已经掌握。

---

## 学习定位

```text
C# / Unity 主线：约 70%
C++ 底层副线：约 20%
算法与复盘：约 10%
```

- 主线目标：具备独立完成 Unity 客户端功能和工程模块的能力
- 副线目标：补足底层认知、C++ 面试与未来引擎开发基础
- 项目目标：每个阶段都留下可运行 Demo、验证记录或复盘，而不只留下笔记

## 总体闭环

```text
确定阶段目标
  ↓
学习已有文章
  ↓
完成最小练习
  ↓
应用到 Demo / 项目
  ↓
用测试、Profiler 或运行结果验证
  ↓
记录问题与复盘
  ↓
回到知识文章补充自己的结论
```

!!! important "完成不等于看完"
    一个知识点至少要经过“能解释、能实现、能验证、能复盘”中的三个环节，才从“学习中”改为“已掌握”。

## 推荐阶段

| 阶段 | 重点 | 阶段产出 |
|------|------|----------|
| 0. 建立学习系统 | 熟悉路线、状态和复盘方式 | 当前学习看板 |
| 1. C# 语言与运行时 | OOP、泛型、事件、集合、内存意识 | 纯 C# 小模块 |
| 2. Unity 核心 | 生命周期、资源、UI、动画、编辑器 | 可运行 Unity Demo |
| 3. C# 工程能力 | GC、异步、测试、模块化、调试 | 可验证的工程模块 |
| 贯穿阶段. 计算机基础 | 算法、组成原理、操作系统、网络与图形数学 | 题解、实验与项目关联 |
| 4. 专项能力 | 性能、图形、网络、热更新 | 专项实验与报告 |
| 5. C++ 副线 | 内存、STL、Modern C++、工具链 | CMake 小项目与算法练习 |
| 6. 综合项目 | 串联多个专题 | 项目复盘与作品集 |
| 7. 面试复盘 | 算法、原理、项目表达 | 面试清单与讲解稿 |

阶段可以交叉进行，但不要同时把所有专题都标为“当前重点”。

## 使用入口

- 不知道接下来学什么：进入对应的[路线页面](csharp-unity.md)
- 补充面试与底层基础：进入[计算机基础路线](computer-science.md)
- 学完后不知道是否掌握：使用[检查清单](../checklists/index.md)
- 完成项目或一周学习：进入[复盘中心](../reviews/index.md)
- 新写文章：使用[知识文章模板](../guides/note-template.md)
- 查具体知识：直接进入原有的 C#、C++、Unity 等专题目录
