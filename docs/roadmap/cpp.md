## 三轮学习法

### 第一轮：能写

- 看懂常用语法、引用、指针和 STL
- 能用 C++ 重写正在学习的算法题
- 不要求掌握模板元编程或无锁结构

### 第二轮：能解释

- 能解释生命周期、RAII、拷贝和移动
- 能说明容器选择与迭代器失效
- 能区分编译错误、链接错误与运行时错误

### 第三轮：能做工程

- 建立 CMake 多文件项目
- 使用调试器或 Sanitizer 定位问题
- 完成一个与 Unity 或引擎开发相关的小实验

## 学习限制

- C++ 学习时间不超过当前总学习时间的约 20%～30%
- 高级主题没有实验支撑时不标记为“已掌握”

- 同一个概念优先记录 C# 与 C++ 的差异，而不是重复抄写定义
